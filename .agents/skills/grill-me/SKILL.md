# Grill-Me — Design Interview

Interview me relentlessly about every aspect of this plan until we reach a shared
understanding. Walk down each branch of the decision tree, resolving dependencies
between decisions one-by-one. For each question, provide your recommended answer.

Ask the questions **one at a time**. If a question can be answered by exploring the
codebase, explore instead of asking.

This is the cold-start entry point for `/define --grill`. Run it before writing
an FSD to resolve the design tree.
